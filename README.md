# Gurla Genie Assistant

Build a polished, responsive web app called “AI Gurla Genie Assistant” — a friendly AI workplace and productivity assistant designed for modern women who want to feel organised, confident, and in control of their workday.

The visual style should be feminine, elegant, professional, and easy to use: use soft pink, lilac, cream, and subtle gold accents, with clear typography, rounded cards, gentle shadows, and a clean modern layout. It must look professional rather than childish.

Create a dashboard layout with:

A left sidebar navigation containing: Dashboard, Task Planner, Research Assistant, AI Chatbot, and Settings.

A responsive design that works beautifully on both desktop and mobile.

Clear input and output sections so users can easily enter requests and understand the AI-generated results.

Include these key features:

AI Task Planner / Scheduler

Let users add tasks, deadlines, estimated duration, and priority level.

Generate a daily or weekly schedule.

Automatically prioritise tasks as High, Medium, or Low priority.

Display the schedule in a clean calendar or timeline-style layout.

Include encouraging messages such as “You’ve got this, girl!” in a tasteful and supportive way.

AI Research Assistant

Provide a text area where users can paste a topic, question, or article.

Generate a short, easy-to-understand summary.

Show key insights, main points, and helpful recommendations.

Use cards or sections labelled Summary, Key Insights, and Recommendations.

AI Chatbot Interface

Create an interactive chat interface where users can ask workplace and productivity questions.

Include example prompts such as:

“Help me prioritise my tasks today.”

“Create a schedule for my week.”

“Summarise this article.”

“How can I prepare for my meeting?”

Show clear chat bubbles for both the user and the AI assistant.

Make the AI responses supportive, practical, professional, and easy to follow.

Add a responsible AI disclaimer at the bottom of the dashboard and chat area:
“AI Gurla Genie Assistant provides general productivity and research support. Please verify important information and use your own judgement when making workplace decisions.”

The app should demonstrate strong prompt engineering through clear user inputs, useful AI-generated outputs, and well-structured results. Prioritise real-world usefulness, innovative productivity support, responsible AI practices, and a high-quality presentation.
